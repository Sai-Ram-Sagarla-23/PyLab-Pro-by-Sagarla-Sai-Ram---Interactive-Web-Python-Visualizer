# PyLab Pro 🐍 

**PyLab Pro** is an open-source, interactive web-based Python IDE, compiler, and code visualizer created by **Sagarla Sai Ram** (Founder & CEO of Medhasya Technologies). 

It provides a seamless, zero-setup browser environment running real CPython where students, developers, and educators can write code, run automated tests, and visualize execution step-by-step.

🚀 **[Launch PyLab Pro Web App](https://github.io)**

---

## 🔥 Key Features

* **Real CPython Environment:** Run Python natively in your browser with full support for core libraries.
* **Data Science Ready:** Pre-configured support for heavy-duty packages like `numpy`, `pandas`, and `matplotlib`.
* **Step-by-Step Code Visualizer:** Watch your code execute line-by-line. Monitor active variables and memory states dynamically to debug logic flaws instantly.
* **Built-in Problem Solver:** Create custom coding problems, define edge-case test suites (input → expected output), and run test cases directly inside the IDE.
* **Full Package Support:** Easily pull in any required package via `pip` directly inside the web UI.

---

## 🛠️ Tech Stack & Architecture

* **Frontend Engine:** HTML5, CSS3, JavaScript (Modern ES6+)
* **Runtime Layer:** WebAssembly-powered CPython architecture
* **Libraries Supported:** Numpy, Pandas, Matplotlib, Custom Pip Modules
